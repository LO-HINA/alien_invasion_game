# Neon Starfighter 霓虹星际战机

Phaser 3 + TypeScript 的竖版/横版自适应弹幕射击。自动射击，专心走位。

## 运行

```bash
pnpm install
pnpm dev        # 开发服务器
pnpm build      # 类型检查 + 打包到 dist/
pnpm preview    # 预览打包结果（默认 4173 端口）
```

| 操作 | 按键 |

## 玩法要点

- **满屏自适应**：逻辑分辨率固定短边 720，长边按窗口比例伸缩（比例夹在 9:16 ~ 2:1 之间），
  配合 Phaser 的 `Scale.FIT`，画布正好铺满窗口、不留黑边。转屏 / 缩放窗口时战场、HUD、
  背景实时重排，战机会按比例挪到新的相对位置。
- **四边出怪**：顶边 40%、左右底各 20%，同一套编队会按照入场边自动换算坐标与前进方向，
  所以「横排」「V 字」「蛇形」从任何一条边进来都成立。敌机穿过战场后从另一侧飞走，不扣血。
- **会反弹的子弹**：主炮子弹体积更大、在场上有存活时间，撞到边界会反弹。
  「弹射弹」技能每级 +1 次反弹、+0.5 秒存活。僚机弹与导弹不反弹（导弹有独立的存活上限）。
- **相位冲刺**：位移期间**完全无敌**且撞到敌机会造成伤害，用来在关键时刻规避弹幕。
  技能每级缩短冷却并提高撞击伤害（3 / 5 / 7 / 10），冷却是 HUD 右下角按钮上的扇形读秒。
- **经验掉在原地**：敌机爆炸后经验以晶体形式留在原地，只有玩家靠近到吸附范围
  （基础 140，磁力回收技能每级提高到 260 / 400 / 560）才会被吸过来。晶体越大代表经验越多，
  同一位置的晶体还会自动合并以免场上堆积。过关结算时会把剩下的晶体全部吸走，不会卡住升级。

## 自动化测试

需要先跑起 `pnpm preview`（或 `pnpm dev`），另开一个终端：

```bash
python scripts/smoke_test.py  http://localhost:4173/ shots   # 主流程 + 三种窗口比例的是否满屏
python scripts/boss_test.py   http://localhost:4173/ shots   # 跳过杂兵直接打 Boss，含中途转屏
python scripts/probe_test.py  http://localhost:4173/         # 判定性探针：入场边分布、吸附范围、结算全吸
```

截图与错误日志会写到 `shots/`（已在 .gitignore 中）。`window.game` 暴露了游戏实例，
可以直接在浏览器控制台里查战局，测试脚本也靠它干预。
