# Alien Invasion Game 🛸

A classic alien invasion-style shooting game built with Python and Pygame.

## Game Features
- Player-controlled spaceship at the bottom of the screen
- Fleets of aliens moving across and down the screen
- Shooting mechanics to destroy aliens
- Score tracking and level progression
